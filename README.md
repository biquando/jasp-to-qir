# Jasp to QIR

This project converts the Jasp MLIR generated by
[Qrisp](https://qrisp.eu/reference/Jasp/MLIR%20Interface.html#jasp-dialect-specification)
to QIR 2.1 LLVM IR for the Adaptive Profile. The target backend is
[Quantinuum's QIR feature set](https://github.com/Quantinuum/qir-qis/blob/main/qtm-qir-reference.md).

## Build/Setup

Dependencies:
- LLVM 21
- MLIR 21 (usually comes with LLVM)

> [!IMPORTANT]
> If LLVM 21 is not your default LLVM version, then set the environment variable
> `export LLVM_BIN=/path/to/your/llvm@21/bin`. This is required for running the
> pipeline and testing framework.

Build the pipeline and install the Python dependencies:

```sh
cmake -S . -B build -DMLIR_DIR=/path/to/your/llvm@21/lib/cmake/mlir
cmake --build build -j

python3 -m venv venv
. venv/bin/activate
pip install -r requirements.txt
```

## Usage

Create a Qrisp/Jasp program, and output MLIR:

```python
# bell.py
from qrisp import *
from qrisp.jasp import make_jaspr, Jaspr

def bell():
    q = QuantumVariable(2)
    h(q[0])
    cx(q[0], q[1])
    return measure(q)

jaspr = make_jaspr(bell)()
assert type(jaspr) == Jaspr
mlir = jaspr.to_mlir(lower_stablehlo=True)  # Make sure StableHLO is lowered!

with open('bell.mlir', 'w') as f:
    f.write(str(mlir))
```

Run your python program to output the MLIR file:

```sh
python bell.py
```

Convert Jasp MLIR to QIR with **dynamic** qubit/result management and **array**
support, the default:

```sh
python tools/jasp_to_qir.py bell.mlir bell.ll
```

Or emit QIR with **static** qubit/result management and **no array** support:

```sh
python tools/jasp_to_qir.py --static bell.mlir bell.ll
```

Use `--keep-intermediates` to retain the generated intermediate files.

Use `--result-buffer-size` to configure the maximum amount of qubits that can be
measured at once, as well as the number of bits outputted with each measurement.
The default is 64.

Because of a limitation of Quantinuum's QIR, recursive functions are not
currently supported.

## Simulating a QIR program

Run a generated QIR file through qir-qis and Selene/QuEST:

```sh
python tools/run_qir.py bell.ll --qubits=2 --shots=10
```

## Testing

```sh
python tests/run_tests.py
```

The test suite generates MLIR programs from Qrisp/Jasp, converts and validates
them in both static and dynamic modes, and compares execution behavior before
and after conversion using Qrisp's simulator and Selene/QuEST. The behavioral
check includes measurement-free state-vector comparisons and deterministic
measurement comparisons.

The state-vector amplitudes and measurement bitstrings from the latest
successful run are stored in:

```text
tests/results/semantic_results.txt
```

When Qrisp test programs change, regenerate their checked-in MLIR fixtures with:

```sh
python tests/generate_qrisp_fixtures.py
```
