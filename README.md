# Jasp to QIR

This project converts the Jasp MLIR generated by
[Qrisp](https://qrisp.eu/reference/Jasp/MLIR%20Interface.html#jasp-dialect-specification)
to QIR 2.1 LLVM IR for the Adaptive Profile. The target backend is [Quantinuum's
QIR feature
set](https://github.com/Quantinuum/qir-qis/blob/main/qtm-qir-reference.md).

## Build/Setup

Build the converter and install the Python dependencies:

```sh
cmake -S . -B build \
  -DMLIR_DIR=/opt/homebrew/opt/llvm/lib/cmake/mlir \
  -DLLVM_DIR=/opt/homebrew/opt/llvm/lib/cmake/llvm
cmake --build build -j

python3 -m venv venv
. venv/bin/activate
pip install -r requirements.txt
```

If LLVM is not installed under `/opt/homebrew/opt/llvm`, then change `MLIR_DIR`
and `LLVM_DIR` in the above commands, and also set `LLVM_BIN=/path/to/llvm/bin`.

## Usage

Create a Qrisp/Jasp program, and output MLIR:

```python
from qrisp import *
from qrisp.jasp import make_jaspr, Jaspr

def bell():
    q = QuantumVariable(2)
    h(q[0])
    cx(q[0], q[1])
    return measure(q)

jaspr = make_jaspr(bell)()
assert type(jaspr) == Jaspr
mlir = jaspr.to_mlir(lower_stablehlo=True)  # Make sure StableHLO is lowered!

with open('bell.mlir', 'w') as f:
    f.write(str(mlir))
```

Convert Jasp MLIR to QIR with **static** qubit/result management and **no
array** support, the default:

```sh
python tools/jasp_to_ll.py bell.mlir bell.ll
```

Or emit QIR with **dynamic** qubit/result management and **array** support:

```sh
python tools/jasp_to_ll.py --dynamic bell.mlir bell.ll
```

Use `--keep-intermediates` to retain the generated `.llvm.mlir` and `.raw.ll`
files.

Use `--result-buffer-size` to configure the maximum amount of qubits that can be
measured at once, as well as the number of bits outputted with each measurement.

Because of a limitation of Quantinuum's QIR, the following are not currently
supported:
- Helper functions that allocate/delete qubits
- Helper functions that return qubits

## Simulating a QIR program

Run a generated QIR file through qir-qis and Selene/QuEST for one shot:

```sh
python tools/run_qir.py bell.ll 2
```

where `bell.ll` is the input QIR file, and `2` is the simulator's max qubit
capacity.

## Testing

```sh
python tests/run_tests.py
```

The test suite generates MLIR programs from Qrisp/Jasp, converts and validates
them in both static and dynamic modes, and compares execution behavior before
and after conversion using Qrisp's simulator and Selene/QuEST. The behavioral
check includes measurement-free state-vector comparisons and deterministic
measurement comparisons.

The state-vector amplitudes and measurement bitstrings from the latest
successful run are stored in:

```text
tests/results/semantic_results.txt
```

When Qrisp test programs change, regenerate their checked-in MLIR fixtures with:

```sh
python tests/generate_qrisp_fixtures.py
```
