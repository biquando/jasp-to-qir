# Jasp to QIR

This project converts the Jasp MLIR generated by
[Qrisp](https://qrisp.eu/reference/Jasp/MLIR%20Interface.html#jasp-dialect-specification)
to QIR 2.1 LLVM IR for the Adaptive Profile.

## Build/Setup

Build the converter and install its Python dependencies:

```sh
cmake -S . -B build \
  -DMLIR_DIR=/opt/homebrew/opt/llvm/lib/cmake/mlir \
  -DLLVM_DIR=/opt/homebrew/opt/llvm/lib/cmake/llvm
cmake --build build -j

python3 -m venv venv
. venv/bin/activate
pip install -r requirements.txt
```

If LLVM is not installed under `/opt/homebrew/opt/llvm`, then change `MLIR_DIR`
and `LLVM_DIR` in the above commands, and also set `LLVM_BIN=/path/to/llvm/bin`.

## Usage

Convert Jasp MLIR with **static** resource management, the default:

```sh
python tools/jasp_to_ll.py input.mlir output.ll
```

To emit QIR using **dynamic** qubit/result management and arrays:

```sh
python tools/jasp_to_ll.py \
  --resource-management dynamic input.mlir output.ll
```

Use `--keep-intermediates` to retain the generated `.llvm.mlir` and `.raw.ll`
files next to the output.

Because of a limitation of Quantinuum's QIR, run-time sized classical buffers
are not supported.

## Testing

```sh
python tests/run_tests.py
```

The test suite generates MLIR programs from Qrisp/Jasp, converts and validates
them in static and dynamic modes, checks expected failures, and compares Qrisp
behavior with QIR executed by Selene/QuEST. It includes unmeasured state-vector
comparisons and deterministic one-shot measurement comparisons.

The state-vector amplitudes and measurement bitstrings from the latest
successful run are stored in:

```text
tests/results/semantic_results.json
```

The report places Qrisp, static-QIR, and dynamic-QIR results together for
visual comparison.

When Qrisp test programs change, regenerate their checked-in MLIR fixtures with:

```sh
python tests/generate_qrisp_fixtures.py
```
